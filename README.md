# MoveMaster - Сервис переездов

## О проекте

MoveMaster - это современный веб-сайт для компании, предоставляющей услуги по переезду. Сайт разработан с использованием Vue.js 3, TypeScript и Vite для обеспечения быстрой и отзывчивой работы.

## Технический стек

- **Фронтенд фреймворк**: Vue.js 3
- **Библиотека UI**: Element Plus
- **Маршрутизация**: Vue Router
- **Сборщик**: Vite
- **Язык программирования**: TypeScript
- **Стили**: CSS с изолированными компонентами (scoped)

## Структура проекта

- `/src/views/`: Содержит основные компоненты страниц
  1. `Home.vue`: Главная страница
  2. `About.vue`: Страница о компании
  3. `Contact.vue`: Страница контактов и формы обратной связи
- `App.vue`: Основной макет приложения
- `main.ts`: Точка входа в приложение
- `style.css`: Глобальные стили

## Локализация

- Сайт доступен на английском языке
- Подготовлен для будущей поддержки нескольких языков

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск сервера разработки
npm run dev

# Сборка для продакшена
npm run build
```

## Дизайн

- Адаптивный дизайн (mobile-first)
- Последовательная цветовая схема (основной цвет #409EFF)
- Использование иконок и компонентов Element Plus
- Чистый, современный интерфейс с достаточным пространством
- Акцент на читаемость и удобство использования
